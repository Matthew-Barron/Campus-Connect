Campus Connect is a web app for students on campus. Right now most things happen in random WhatsApp groups, Facebook Marketplace and posters, and it's easy to miss stuff. We wanted one place where verified students can sell second-hand things, find events, join societies and find a tutor. That's what this app does.
 
What you can do on it
 
- Accounts: sign up with your student email, log in and reset your password if you forget it.
- Marketplace: post a listing, edit it or delete it, mark it as available or sold, and browse what other students are selling.
- Events: see events, RSVP, and leave an event again if your plans change.
- Polls: vote on a poll with several options. You can only vote once, and you can see the results.
- Societies: browse societies, join or leave them. Society admins can see their member list, so no more spreadsheets.
- Tutoring: post a tutoring listing, edit or delete it, and filter listings by subject.
- Notifications: an in-app feed with an unread count for new events, poll updates and RSVP confirmations.
 
It's made to work on phones, tablets and desktops, and you should be able to get to any part of it in 3 clicks. The main pages should load within 3 seconds for about 50 people at a time.
 
Where to find it
 
Live site: https://campus-connect-tba3.onrender.com/#marketplace
Code: https://github.com/Matthew-Barron/Campus-Connect.git
 
How it's built
 
- Front end is hosted on Render.
- The back end and database run on Supabase.
- The code is kept on GitHub.
 
How to try it
 
1. Open the live site link above.
2. Create an account with a student email address.
3. Log in and have a look around. The marketplace is the first page you land on.
 
If you want to run it on your own computer, clone the repo from the link above. We didn't write full local setup steps here, so check the repo files for what it needs.
